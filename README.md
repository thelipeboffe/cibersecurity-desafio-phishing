# Phishing para captura de credenciais utilizando SEToolkit

## Ferramentas

- Kali Linux  
- SEToolkit  

## Configurando o Phishing no Kali Linux

Acesso root:

```bash
sudo su
```

Iniciando o SEToolkit:

```bash
setoolkit
```

Tipo de ataque:

```text
Social-Engineering Attacks
```

Vetor de ataque:

```text
Web Site Attack Vectors
```

Método de ataque:

```text
Credential Harvester Attack Method
Site Cloner
```

Obtendo endereço da máquina:

```bash
ifconfig
```

URL utilizada para clone:

```text
https://www.facebook.com
```

## Resultados

- Página clonada com sucesso  
- Captura de credenciais de teste realizada  
- Usuário e senha identificados via payload enviado no formulário  
- Validação do funcionamento do Credential Harvester em ambiente de laboratório
